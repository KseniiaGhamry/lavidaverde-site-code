## Сайт и назначение
- `https://lavidaverde.ae/` — самостоятельный экран выбора рынка/страны, а не весь сайт.
- Первая кнопка **UAE & GCC / الإمارات والخليج** → `https://lavidaverde.ae/uae`.
- Вторая кнопка **Egypt / مصر** → `https://lavidaverde.ae/egypt`.
- Не менять страницы `/uae` и `/egypt`, глобальные стили Tilda или HEAD при редактировании входной страницы.
- Используется один **T123** в Tilda. В V3.2 CSS, SVG-стрелки, логотип PNG (встроенный base64) и скрипт языков находятся внутри целого файла; внешняя зависимость только фотография.

- **Первая кнопка**: `#646e57`; вторая полупрозрачная `rgba(31,39,23,.24)`.

Это деликатное затемнение **только карточки**, не всей фотографии. Радиус карточки 23px мобильный, 28px десктопный.

## Логотип: особо защищённый объект
- **La Vida Verde** как графическое название без дескриптора и без линий. Не заменять браузерным шрифтом.
- Актуальный PNG **371×65 px**, RGBA, со свободными прозрачными полями по краям; его восстановление исправило обрезание букв.
- Встроен `data:image/png;base64,...` в сам T123. Реальные цветные пиксели `#f1ecd3`.
- Визуально сверху слева, левая линия совмещена с основным заголовком, уровень по высоте соответствует языкам справа.
- Итоговая CSS-поправка V3.2 для `.lvvg3 .lvvg3__brand`: `width:clamp(258px,18.22vw,372px)`; `max-width:none;height:auto;flex:0 0 auto;object-fit:contain;overflow:visible;transform:translate(-3.3%,-17%)`. На мобильном ширина `clamp(190px,61.6vw,295px)`, особая высота header и `overflow:visible`.
- Никогда не обрезать PNG впритык и не терять прозрачные поля. Проверять десктоп и мобильный в EN/AR.
